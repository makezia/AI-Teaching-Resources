# Code Examples & Projects

This directory contains practical code examples and mini-projects for teaching AI and machine learning.

## Organization

### By Topic
- **Machine Learning**: Classification, regression, clustering
- **Deep Learning**: Neural networks, CNNs, RNNs
- **Natural Language Processing**: Text analysis, sentiment analysis
- **Large Language Models**: Prompt engineering, API usage
- **Data Science**: Exploratory analysis, visualization

### By Difficulty
- **Beginner**: Basic concepts, guided examples
- **Intermediate**: Small projects, moderate complexity
- **Advanced**: Complex applications, research examples

## Example Structure

Each example includes:
- `README.md` - Description and instructions
- `code.py` - Python implementation
- `requirements.txt` - Dependencies
- `data/` - Sample data (if applicable)
- `output/` - Expected output examples

## Running Examples

### Prerequisites
```bash
python --version  # Python 3.8+
pip install -r requirements.txt
```

### Basic Workflow
```bash
cd example-name
python code.py
```

## Tips for Learning from Examples

1. **Read First**: Understand what the code does
2. **Run It**: Execute with provided data
3. **Modify It**: Change parameters and see results
4. **Extend It**: Add features or use different data
5. **Debug It**: Add print statements to understand flow
6. **Document It**: Add your own comments

## Common Pitfalls to Avoid

- ❌ Overly complex examples
- ❌ Hard-coded file paths
- ❌ Missing explanations
- ❌ No comments in code
- ❌ Untested code
- ❌ Missing dependencies in requirements.txt

## Using in Classroom

### For Instruction
1. Walk through the code together
2. Explain each step
3. Run and show output
4. Discuss results
5. Ask students to modify it

### For Assignments
1. Start students with example code
2. Ask them to modify or extend it
3. Have them adapt to new data
4. Encourage creativity

### For Self-Study
1. Read the explanation
2. Review the code
3. Run and experiment
4. Try variations
5. Move to more complex examples
